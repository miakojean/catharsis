### Comment faire une feature!

#### On passe par uv et bun comme runtime python et Node.

1- Vérifie dans backend si la feature a déjà été implémentée. Quand elle est faite tu passes au frontend sinon tu proposes un plan détaillé pour implémenter la feature côté backend

2- Ensuite on passe par l'implémentation côté front

3- Pour les composants tu vérifies s'il y a des composants déjà créés, si oui tu les utilises sinon tu crées un module dans component dans lequel tu vas ajouter le composant créé.

4- Pour l'ux/ui tu es expert webdesigner; nous avons une palette de couleurs déjà implémenté dans le fichier main.css tu les utilises en fonction des besoins relatifs au features.
